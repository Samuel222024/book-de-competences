Projet PAF — Pénétration & Attaque Furtive

Projet Coup de Cœur
Outil d'intrusion physique dissimulé dans une fausse borne Wi-Fi Ubiquiti, établissant un point d'accès persistant et furtif sur le réseau interne cible.

Le dispositif intègre un Raspberry Pi configuré pour opérer furtivement dès son branchement physique. Il établit une communication chiffrée sortante (callback Socat) vers un serveur de rebond intermédiaire (vps offshore), qui masque la localisation finale du C2. Il permet d'exécuter des actions d'audit et de pivoting interne sans éveiller les alertes de périmètre traditionnelles.

Projet Enigma — Automatisation d'Audits Pentest

Outillage Pentest
Framework Bash modulaire permettant de standardiser la phase de reconnaissance et d'audit technique selon le périmètre ciblé, avec génération automatique de livrables HTML.

Face à la dispersion des outils de diagnostic en test d'intrusion, Enigma rassemble au sein d'une interface console intuitive les modules spécialisés (Active Directory, scans réseaux, endpoints Windows/Linux, apps web). Le script vérifie dynamiquement les prérequis système et structure les résultats en rapports exploitables.

bash — ./enigma.sh — Terminal Interactif
samuel@esgi-reims:~$ ./enigma.sh --interactive
[+] Enigma Pentest Framework v2.4 initialisé.
[+] Contrôle des dépendances : Nmap (OK) | Impacket (OK) | BloodHound (OK) | Nikto (OK)
[i] Prêt. Cliquez sur un bouton de commande ci-dessus pour simuler l'exécution.
ℹ️ La démonstration ci-dessus est représentative du fonctionnement réel d'Enigma : les modules d'audit (Active Directory, réseau, web), la vérification des dépendances et la génération de rapport HTML sont directement issus du script enigma.sh développé dans le cadre du projet. Le terminal interactif illustre les flux d'exécution du code réel.
